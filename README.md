# Instant Riptide

A Fabric mod for Minecraft that lets you use a Trident with Riptide while standing on dry ground.
The mod pours water under the player's feet on its own (and picks it back up into a bucket after
the launch), and can also auto-deploy the elytra the instant the player leaves the ground after a
ground-riptide launch.

## Runtime dependencies

- [Fabric Loader](https://fabricmc.net/use/installer/)
- [Fabric Api](https://modrinth.com/mod/fabric-api)
- [Mod Menu](https://modrinth.com/mod/modmenu)
- [Cloth Config API](https://modrinth.com/mod/cloth-config)

## Compilation dependencies

- Loader (`net.fabricmc:fabric-loader`)
- API (`net.fabricmc.fabric-api:fabric-api`)
- Mod Menu (`maven.modrinth:mOgUt4GM`)
- Cloth Config (`maven.modrinth:9s6osm5g`)
